Who it serves,
and what it costs.

Submit a Lean statement and choose a model and budget. TheoremOS runs the research and the independent check.

Math agent researchers

Keep the problem, model and budget fixed, then swap the search, context or collaboration strategy to see which works better. Every attempt keeps its candidates, diagnostics and usage.

Lean and Mathlib users

Hand a theorem with sorry to a model. A result counts only when the full statement passes an independent Lean check, and you can download the source and the report.

Cost

The platform is free during the research preview. Model calls use your own API key and are billed at your provider's prices. Set turn and time limits before you submit. A run lasts at most 15 minutes.

Before you start.

How do I request access?

Open an early access request on GitHub and describe your research use and the problems you want to work on. We will reply in the same issue when the workbench opens and ask you to email us the address you will sign in with. Once it is on the allowlist, you sign in with a code sent to that address. Requests are public, so do not include API keys, email addresses or other personal information. Without GitHub, or to apply privately, email liuzhenhao@westlake.edu.cn with your research use and the problems you want to work on.

What is it for?

It is built for math agent researchers and Lean developers: building proofs, comparing search and collaboration methods, and reviewing research experiments. This is a research preview.

Can I run proofs in the browser?

The online workbench is coming soon. Once it opens, you can submit Lean and Mathlib statements in the browser, enter your own API key and see the verification result. For now the site offers interface screenshots, a recorded replay and the proof archive.

Which API keys are supported?

The online workbench works with OpenAI and services compatible with the Responses API. Research runs incur usage with your provider. The recorded replay on this site does not call a model and needs no API key.

Does the web workbench keep my research records?

Run records are stored on the server under your account, and you can download the source and reports. All records are deleted when you delete your account. Your API key exists only in memory during a run and is never written to disk or browser storage. See Privacy and terms.
